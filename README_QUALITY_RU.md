# Оценка качества по одному принятому сигналу

В текущем модеме выбрана оценка SINR по известным пилотам с комплексным методом наименьших квадратов и отдельная EVM по CRC-проверенным данным. Исходный текст/изображение для этих метрик не нужен. Это практический выбор под существующий пакетный формат и все его модуляции; универсальной оптимальности для произвольного канала или помехи не утверждается.

## Какие статьи исследованы

1. [D. R. Pauluzzi, N. C. Beaulieu, A Comparison of SNR Estimation Techniques for the AWGN Channel, IEEE, 2000](https://doi.org/10.1109/26.871393). [Полный текст, размещённый соавтором](https://www.researchgate.net/publication/3160255_A_comparison_of_SNR_estimation_techniques_for_the_AWGN_channel). Работа сравнивает оценки по известной последовательности, решениям приёмника и статистическим моментам. Если обучающие символы уже передаются, их использование не требует дополнительного эфирного времени. Вывод для реализации: использовать существующие пилоты вместо неизвестных жёстких решений payload.
2. [F. Bellili и соавторы, Maximum Likelihood SNR Estimation of Linearly-Modulated Signals over Time-Varying Flat-Fading SIMO Channels, 2014](https://arxiv.org/abs/1411.4763). Рассмотрены DA/NDA-оценки, локальная модель меняющегося канала и смещение на конечной выборке. Вывод для реализации: оценивать локальное усиление в каждом пилотном блоке и учитывать потраченные степени свободы. Здесь применяется простая одноантенная постоянная модель блока; полный алгоритм статьи с полиномиальным каналом и EM не воспроизводится.
3. [R. M. Rao, V. Marojevic, J. H. Reed, Semi-Blind Post-Equalizer SINR Estimation and Dual CSI Feedback for Radar-Cellular Coexistence, 2020](https://arxiv.org/abs/2006.01327). Импульсная помеха может по-разному воздействовать на пилоты и данные. Авторы исследуют дополнительную эвристику максимума расстояния до ближайшей точки и комбинированную оценку для LTE. Вывод для нашего модема: пилотный SINR следует показывать вместе с CRC/PER и охватом данных; переносить LTE-эвристику без проверки на ASK/FSK нельзя.
4. [T. Brown и соавторы, Prediction of SINR using BER and EVM for Massive MIMO Applications, 2018](https://arxiv.org/abs/1809.07811). Исследована связь EVM с SINR и влияние модуляции, характера помех и усреднения. Вывод для реализации: EVM полезна как дополнительная характеристика, но не даёт универсального разделения мощности шума и помехи.

## Основной оцениватель

Пилоты известны из выбранного профиля и seed. После общей синхронизации и удаления CP, до подгонки фазы/канала по тем же пилотам, получаем наблюдения:

- ASK/PSK/QAM: среднее центральных четырёх отсчётов каждого пилотного символа;
- 2-FSK: комплексные выходы обоих корреляторов. Эталон — отклик этих же корреляторов на идеальный тон с выбранной девиацией. Для ортогональных тонов это [1,0] или [0,1]; при произвольной девиации учитывается взаимный отклик.

Пусть x — известный вектор, y — принятый, y = h x + e. Подгоняется один комплексный коэффициент h на пилотный блок. N — число комплексных компонент (для FSK их две на символ).

Формулы реализации:

    E = sum(abs(x)**2)
    h_hat = vdot(x, y) / E
    residual = y - h_hat*x
    variance_hat = sum(abs(residual)**2) / (N-1)
    signal_energy = max(abs(h_hat)**2 * E - variance_hat, 0)
    disturbance_energy = N * variance_hat

При независимом белом комплексном шуме поправки устраняют смещение оценок мощностей от одного подогнанного комплексного коэффициента. Само их отношение на короткой выборке всё ещё смещено. При коррелированной помехе, изменении канала, синхронизации по шумным данным или выборе выровненной позиции статистические гарантии этой упрощённой модели ограничены.

Энергии накапливаются по уникальным DATA-пакетам; дубликаты и END не улучшают статистику. Финальные значения:

    SINR_pilot_dB = 10*log10(sum(signal_energy) / sum(disturbance_energy))
    EVM_pilot_percent = 100*sqrt(sum(disturbance_energy) / sum(signal_energy))

Отношение с практически нулевым остатком ограничено сверху 120 dB для конечного JSON-значения. Это численный предел, не аппаратный динамический диапазон. Нулевое число пригодных отсчётов/неположительная оценка сигнала дают null, не выдуманное качество.

При неортогональных тонах FSK шумы двух корреляторов коррелированы. Модель эталона учитывает перекрытие тонов; конечновыборочная поправка N−1 в этом случае приближённая. При малой девиации тоны хуже различимы, поэтому высокий SINR сам по себе не гарантирует низкий BER.

Название SINR здесь означает отношение модели полезного сигнала к остаточным помехе, шуму и искажениям в пилотных наблюдениях до эквализации. Это не RF-измеритель, не чистый SIR, не Eb/N0 и не общая паспортная помехозащищённость. Для FSK учитываются ошибки двух корреляторов: в белом шуме такой векторный SINR на 3 dB ниже отношения энергии символа к дисперсии шума одного коррелятора. Сравнение разных демодуляторов должно учитывать эту разницу и точку измерения.

## Дополнительная EVM данных

Только при верной CRC тела принятый payload локально дополняется и повторно кодируется теми же whitening и модуляцией. Это даёт ожидаемые символы без внешнего файла. Они сравниваются с наблюдениями до жёсткого решения, после коррекции по пилотам и SC-FDE (если используется).

    EVM_crc_percent = 100*sqrt(sum(abs(observed-expected)**2) / sum(abs(expected)**2))

Учитываются только полные символы пользовательской части, без CRC и PHY-padding. Для FSK используются оба комплексных коррелятора. Канал не подгоняется по восстановленному payload.

Эта метрика доступна только на успешно принятых пакетах и потому при ошибках имеет смещение отбора. Интерфейс показывает долю CRC-верных среди принятых пакетов; общее число ожидаемых, CRC-ошибок и потерь видно рядом. При CRC BAD оценка его payload EVM отсутствует. Контроль CRC не является абсолютным доказательством отсутствия ошибок, но резко уменьшает риск использовать неверные решения как эталон.

## Что нельзя заключить из одного потока

- Раздельные мощности внешней помехи, собственного шума и остаточного искажения без дополнительных предположений не идентифицируются.
- При отсутствии синхронизации/валидного заголовка нельзя установить ID, число переданных пакетов или SINR полезного сигнала. Спектр доступен, остальные метрики неизвестны.
- Импульс между пилотами может оставить их SINR высоким. CRC/PER/потери и предупреждение об охвате предотвращают трактовку такого SINR как гарантии приёма данных.
- Искажённые биты и пиксели без эталонного содержимого не подсчитываются. Их число остаётся null; CRC BAD не превращается в произвольное число битовых ошибок.
- Предельную помехозащищённость определяют испытанием при меняющейся помехе и фиксированных условиях, например достижением заданного PER. Здесь оценивается текущее качество принятой части.

## Почему не только слепой M2/M4 или ближайшая точка

Методы моментов требуют подходящей статистической модели созвездия/шума; одна формула для постоянной огибающей не подходит всем ASK/QAM. Жёсткие решения могут выбрать соседнюю точку и уменьшить видимый остаток при реальных битовых ошибках. Полный NDA-ML/EM значительно сложнее, а в этом кадре уже есть известные пилоты. Поэтому выбрана малозатратная DA/LS-оценка с явными ограничениями и дополнительной CRC-проверкой данных. Это инженерная адаптация идей статей, а не заявление об их дословной реализации.

## Проверки

В test_quality.py проверяются средние оценки мощностей на 1500 реализациях известного AWGN для линейных и двухкорреляторных векторов, снижение SINR с ростом шума во всех восьми модуляциях, независимость от выбора внешнего эталона, отсутствие повторного учёта дубликатов и импульсная инверсия символа исключительно между пилотами. Последний тест специально сохраняет высокий SINR пилотов, но вызывает CRC BAD, отсутствие EVM данных и предупреждение об ограничении оценки.

Проверки выполняются на синтетических IQ. Аппаратные эффекты Pluto/HackRF и устойчивость метрик к реальной помехе требуют проверки на стенде.
