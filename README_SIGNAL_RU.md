# Формат сигнала: PHY v2

Вся передача использует выбранную модуляцию: преамбула, маркер, пилоты, защищённый заголовок, тело и END. TX и RX должны иметь один профиль. Автоматического определения модуляции или старого BPSK-заголовка нет. Обновляйте обе стороны одновременно: PHY v1 несовместим с v2.

Это пакетный однонесущий модем; при CP используется SC-FDE для линейных модуляций данных. OFDM и RRC-фильтра в этом тракте нет. Один символ занимает SPS = 8 комплексных отсчётов; Rs = Fs/8, Fs выбирается 1 или 2 MS/s.

## Профиль

| Параметр | По умолчанию | Допустимые значения |
|---|---:|---|
| Модуляция | BPSK | ASK/OOK, 2-FSK, BPSK, QPSK, 8-PSK, QAM-4/16/64 |
| Преамбула | включена, 256 символов | 64…4096 символов |
| Seed преамбулы | 331 | 0…2³²−1 |
| Циклический префикс | выключен, длина 16 | 1…256 символов, не длиннее блока |
| Пилоты в блоке | 32 | 8…256 символов |
| Seed пилотов | 7729 | 0…2³²−1 |
| Символы данных в блоке | 128 | 32…1024 |
| Данные в пакете | 768 байт | 48…12288 байт |
| Поворот QPSK/8-PSK | 0° | −180…180°; у BPSK и QAM отдельных настроек нет |
| Нижний уровень ASK | 0, то есть OOK | 0…0.9 от верхнего |
| Девиация каждого тона FSK, МГц | 0.125 | Больше 0 и меньше Fs/4 в МГц: 0.25 при 1 MS/s, 0.5 при 2 MS/s |

Профиль имеет контрольную сумму CRC32, защищённую CRC заголовка. Диапазон поиска CFO — локальная настройка RX; он не входит в эту сумму. Совпадать должны активные настройки. При выключенном CP его длина не входит в контрольную сумму; при выключенной преамбуле её длина и seed также исключаются. Неактивные настройки других семейств модуляции в сумму не входят.

ASK/PSK/QAM нормированы к единичной средней энергии по всему созвездию. PSK и квадратная QAM имеют Gray-разметку. ASK с ненулевым нижним уровнем остаётся двухуровневой амплитудной модуляцией. BPSK имеет фиксированное созвездие −1/+1, QAM-4/16/64 — фиксированные квадратные решётки без настройки поворота. Девиация FSK задаётся в интерфейсе в МГц: тоны расположены на f₀−Δf и f₀+Δf, разнос равен 2Δf. Допускаются произвольные положительные значения ниже Fs/4. При целочисленном 2Δf/Rs тоны ортогональны; при остальных значениях эталоны метрик учитывают взаимный отклик корреляторов. Поле Config.fsk_deviation_hz хранит девиацию в герцах; число циклов на символ выводится из Δf и Fs.

## Кадр

Цикл Pluto TX: DATA 0 → … → DATA N−1 → END → END → END. Новый цикл получает новый случайный ID; данные разных циклов не объединяются. RX сохраняет текущую передачу по END и продолжает приём до Stop. Другой ID собирается в отдельный буфер; незавершённая основная передача продолжает собираться и отображаться. Совпадающий эталон имеет приоритет при выборе основной передачи. Повторные END того же ID и END сторонней передачи не останавливают RX. Если DATA 0 потерян, первый валидный заголовок DATA 1 или более позднего пакета позволяет начать сборку.

Каждый кадр содержит:

1. Преамбулу, если включена: известную псевдослучайную последовательность символов выбранного созвездия.
2. Маркер: ровно 64 символа выбранной модуляции, построенных из повторов MAGIC d391c5a76e2b48f0. Постоянное число символов сохраняет длину поискового шаблона при смене порядка модуляции.
3. Блоки заголовка: каждый бит после whitening повторяется трижды, группы битов отображаются в выбранное созвездие, затем дополняются до целого числа блоков.
4. Блоки тела: область payload_bytes байт плюс CRC32 реальных данных. Эта PHY-длина одинакова для DATA и END в пределах профиля.

Блок имеет вид [CP, если включён] [pilot_symbols пилотов] [data_symbols символов]. Дополнение последнего блока тоже состоит из допустимых символов выбранной модуляции, включая FSK. Пилоты не несут пользовательских данных и не исправляют ошибки.

Pluto добавляет до и после кадра по 12 мс нулевых IQ и после буфера ждёт заданную паузу (по умолчанию 20 мс). Нулевые защитные интервалы обозначают отсутствие сигнала. Амплитуда TX по умолчанию 16384 с диапазоном 1…16384; аппаратное усиление задаётся отдельно.

## Заголовок

54 байта: 50 байт полей и 4 байта CRC32.

| Поле | Байт |
|---|---:|
| Версия (2), тип (text/RGB), индекс модуляции, флаги | 4 |
| ID передачи | 8 |
| Номер DATA / общее число DATA / размер исходника | 12 |
| Ширина / высота / реальная длина payload | 6 |
| Первые 16 байт SHA-256 исходника | 16 |
| CRC32 профиля | 4 |
| CRC32 заголовка | 4 |

Заголовок после тройного повторения содержит 1296 бит. При k бит/символ он занимает ceil(ceil(1296/k)/data_symbols) блоков. RX сначала демодулирует биты, затем выполняет решение большинством и проверку CRC, версии, профиля, размеров, последовательности и длины. Пользовательские данные FEC не имеют.

CRC заголовка/тела обнаруживает ошибки; SHA-256 позволяет проверить независимо выбранный эталон. Whitening с фиксированным seed заголовка и зависящим от ID/seq seed тела устраняет повторяющиеся битовые структуры и не является шифрованием.

## Пользовательские данные

Текст UTF-8 делится на последовательные участки выбранного размера. Последний неполный участок дополняется до PHY-длины нулями; CRC считается только по реальной части. END имеет length = 0 и ту же PHY-длину.

Для RGB число пикселей плитки — floor(payload_bytes/3). Ширина — наибольший делитель этого числа, не превосходящий его квадратного корня; высота — частное. При 768 байтах получается 16×16, при 192 — 8×8. Плитки идут слева направо и сверху вниз; неполные края дополняются нулевыми RGB-пикселями. Если размер пакета не кратен трём, оставшиеся PHY-байты не несут пиксели.

GOOD: верные заголовок и CRC тела. CRC: заголовок принят, тело повреждено; принятые байты всё равно показываются. LOST: пакет отсутствует после завершения передачи. До END/Stop это ожидаемые или потерянные пакеты. Потерянные RGB-пиксели остаются серыми (128,128,128).

## Синхронизация, пилоты и CP

Первые 32 символа преамбулы используются для грубого корреляционного поиска и CFO-сетки, первые 64 — для точной оценки CFO. Если преамбула выключена, поиск использует маркер. Нормировка корреляции учитывает фактическую энергию выбранного шаблона, включая нулевые уровни OOK и разные амплитуды QAM.

Известный маркер уточняет фазу и CFO. Пилоты каждого блока отслеживают положение блока, фазу, остаточный CFO и комплексное усиление. Нулевые OOK-пилоты исключаются из подгонки фазы; как минимум два пилота активны. Это не меняет выбранную модуляцию.

CP копирует хвост блока перед его началом и удаляется на RX. Для линейного payload при включённом CP применяется регуляризованная частотная эквализация с LS-моделью канала длиной 9 IQ-отсчётов. Заголовок использует коррекцию по пилотам без SC-FDE. Для FSK эквалайзер не применяется; CP остаётся защитным интервалом. Удлинение CP не увеличивает длину модели канала. CP полезен при отражениях и межсимвольной интерференции, но не устраняет шум, клиппинг и неверную настройку частоты.

## Длительности при стандартном профиле

Преамбула 256, пилоты 32, данные блока 128, payload 768, Fs = 1 MS/s. Учтены преамбула, маркер, заголовок, тело; не учтены тишина до/после и пауза после буфера.

| Модуляция | Бит/символ | Блоки заголовка | Блоки тела | Без CP, мс | С CP 16, мс |
|---|---:|---:|---:|---:|---:|
| ASK/OOK, 2-FSK, BPSK | 1 | 11 | 49 | 79.360 | 87.040 |
| QPSK, QAM-4 | 2 | 6 | 25 | 42.240 | 46.208 |
| 8-PSK | 3 | 4 | 17 | 29.440 | 32.128 |
| QAM-16 | 4 | 3 | 13 | 23.040 | 25.088 |
| QAM-64 | 6 | 2 | 9 | 16.640 | 18.048 |

При 2 MS/s радиокадр вдвое короче. Rs возрастает с 125 до 250 ксимв/с; полоса и нагрузка обработки растут. Формула длины блока: (pilots + data + cp_if_enabled) × 8 отсчётов. Длина тела: ceil(ceil((payload_bytes+4)×8/k)/data_symbols) блоков. Длительности вычисляются программой из профиля.

## Радиочастота и спектр

Pluto LO устанавливается в выбранный центр − Fs/4. Передача цифрово сдвигается на +Fs/4, RX обратно на −Fs/4. Это сохраняет OOK от подавления DC-компенсацией. Встроенная вкладка «Спектр» показывает сырой принятый IQ до обратного сдвига: абсолютная ось строится вокруг фактического RX LO, а отдельная линия показывает выбранный центр полезного сигнала. Обновление до 10 раз/с, FFT до 4096 отсчётов с окном Hann, шкала dBFS на FFT-ячейку. Расчёт идёт до squelch и не требует распознанного заголовка. Узкие пики сохраняются при уменьшении числа точек для отрисовки.

HackRF TX-emitter использует тот же профиль, а затем передискретизирует IQ на аппаратный sample rate HackRF. Частота дискретизации профиля RX задаётся отдельно (1 или 2 MS/s). В пакетном режиме он повторяет DATA 0 с одним ID до Stop, END не передаёт. В непрерывном фиксированном режиме граница IQ-цикла совпадает с границей кадра. Импульсный и скользящий режимы могут обрезать кадр.

## Измерения

BER и число искажённых битов требуют совпавший внешний эталон. Потерянные пакеты/пиксели считаются по заголовку и уникальным принятым номерам. Число искажённых пикселей сравнивает реальные RGB-области, не padding; несколько изменённых каналов одного пикселя дают один пиксель.

Оценки SINR по пилотам и EVM CRC-проверенных данных доступны без внешнего эталона. Они имеют разные точки измерения (до эквализации и после коррекции) и не должны механически объединяться. Математика, исследованные статьи и ограничения приведены в [README_QUALITY_RU.md](README_QUALITY_RU.md). Качественный приём на одном уровне помех не определяет предельную помехозащищённость: для этого нужна серия измерений PER/потерь при изменяемой помехе.
